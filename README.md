# Стартер второго мозга

Отдаёшь эту папку своему агенту, и он сам расспрашивает тебя и собирает
второй мозг проекта под тебя: CLAUDE.md или AGENTS.md, папки с правилами и
программу проверки. Работает с Claude Code, Codex, Cursor, Gemini CLI,
GitHub Copilot, Windsurf, Hermes. Если агентов несколько в одной папке,
стартер соберёт AGENTS.md, а CLAUDE.md сделает ссылкой на него.

## Как запустить

1. Скопируй текст установки из поста в канале или из описания релиза
   на GitHub - в нём ссылка на архив.
2. Открой своего агента в папке проекта и вставь ему этот текст. Агент сам
   скачает архив, проверит его и поставит стартер.
3. Дальше агент ведёт сам: задаёт вопросы по одному и без твоего «да»
   ничего не меняет.

Займёт 30-60 минут, прерваться можно после любого шага.

## Что получишь

- второй мозг до 150 строк: что за проект, где что искать, чего нельзя;
- папки `ai-clone/`, `business/`, `rules/`, `plans/`, `prompts/`, `tools/`
  с твоими ответами;
- `tools/check-claude-md.py`: проверка без нейросети, проверяет адреса,
  сирот, дубли, ключи и длину;
- `prompts/pohudenie.md`: промпт похудения на случай, когда файл
  разрастётся.

Ключи, пароли и данные клиентов стартер в файлы не пишет.
